# CrossPoint Reader — Claude Context

## What this project is

CrossPoint Reader is open-source firmware for the **Xteink X4** e-paper display reader (ESP32-C3 microcontroller, 16MB flash). It replaces the proprietary factory firmware and supports EPUB 2/3, XTC (custom format), and TXT files with WiFi sync, OTA updates, and a web UI for configuration.

## Directory structure

| Path | Contents |
|---|---|
| `src/` | Main firmware source (Arduino/C++). UI is organized as "activities": boot, home/library, reader, network (WiFi/Calibre/OPDS/news sync/web server), settings |
| `lib/` | C++ libraries: EPUB parser, XTC/TXT handlers, GfxRenderer (display), EpdFont (Bookerly/Noto/OpenDyslexic fonts), OPDS browser, KOReader sync client, ZipFile, UTF-8 |
| `scripts/` | Python utilities: `news_sync_server.py` (OPDS feed + EPUB/XTCH build), `build_index.py` (Bloomberg-style web reader index), `epub_to_xtch.py` (format converter), `debugging_monitor.py`, `generate_hyphenation_trie.py` |
| `scripts/news_sync_docker/` | Docker Compose setup: `news_sync` (calibre + news build, port 8081) and `news_web` (nginx reader, port 8082) services. Output at `data/news_out/` |
| `recipes/` | Calibre news recipes: Bloomberg, Businessweek, WSJ, NYTimes, NPR Text, Substack |
| `docs/` | Technical docs: file formats, web server endpoints, troubleshooting |
| `open-x4-sdk/` | Submodule — X4 hardware drivers |
| `test/` | Test files and evaluation scripts |

## Tech stack

- **Platform:** PlatformIO + espressif32 @ 6.12.0 (Arduino framework)
- **MCU:** ESP32-C3, 16MB flash, ~380KB usable RAM
- **Build:** `platformio.ini`; pre-build step `scripts/build_html.py` converts `src/**/*.html` → C++ `PROGMEM` headers
- **Libs:** ArduinoJson, SdFat, WebSockets, PNGdec, QRCode, expat, miniz
- **CI:** GitHub Actions — cppcheck, clang-format, PlatformIO build

## News sync Docker stack

Two services in `scripts/news_sync_docker/docker-compose.yml`:

- **`news_sync`** (port 8081): Runs Calibre recipes → generates EPUB bundles → writes `news.xml` OPDS feed → serves via Python `http.server`. Schedule is internal sleep-loop in `entrypoint.sh` (not host cron). Default refresh every 60 min.
- **`news_web`** (port 8082): nginx:alpine serving `data/news_out/` read-only. Landing page at `index.html` (Bloomberg-style, generated by `build_index.py`). Article HTML extracted from EPUB ZIPs by `build_index.py` into `data/news_out/articles/`.

Access on Mac mini target (`192.168.2.103`, user `sternaman`, path `/Users/sternaman/services/newsreader`) over Tailscale. No auth/TLS at the nginx layer.

OPDS feed (for X4 device): `http://<host>:8081/news.xml`
Web reader: `http://<tailscale-ip>:8082`

## Key scripts

| Script | Purpose |
|---|---|
| `scripts/build_html.py` | Firmware build step — minifies `src/**/*.html` → C++ PROGMEM headers. Unrelated to news HTML. |
| `scripts/news_sync_server.py` | Runs Calibre recipe → EPUB/XTCH bundle, writes OPDS feed XML |
| `scripts/build_index.py` | Extracts article HTML from EPUBs, generates Bloomberg-style `index.html`, downloads fonts once |
| `scripts/epub_to_xtch.py` | Converts EPUB → XTCH (X4 native format) |

## EPUB internal structure (Calibre output)

```
content.opf              ← OPF metadata (dc:title = source name, dc:creator = date)
feed_N/index_*.html      ← Section TOC: section name + article list with descriptions
feed_N/article_M/        ← Article directory
  index_*.html           ← Article HTML (h1 = headline, .auth = byline)
  images/                ← Inline images (relative refs from HTML)
stylesheet.css           ← Calibre CSS (stripped by build_index.py, replaced with reader.css)
```
